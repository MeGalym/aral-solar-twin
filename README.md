# Арал 30 — цифровой двойник СЭС

Интерактивная 3D-модель солнечной электростанции 30 МВт (Аральск): 522 трекера, 42 282 панели, 82 инвертора, 4 КТП.

Четыре вкладки:

- **Девелопмент** — площадка на спутниковой карте с зонами ограничений, источники солнечного ресурса, импорт чертежей, автоматическая расстановка рядов и сравнение сценариев компоновки, финмодель с чувствительностью.
- **Эксплуатация** — мощность, температура и отклонения по каждой панели, наряды на отказы; разделы «Расчёт и факт», SCADA (имитация потока), датчики, предиктивная диагностика, ограничение мощности и накопитель.
- **Стройка** — ход работ на дату, план и факт, склад модулей, замечания ОТК.
- **Смета** — структура стоимости, ведомость объёмов, LCOE и окупаемость.

Геометрия и смета взяты из рабочего проекта. Телеметрия и фактический ход стройки — расчётная модель и демонстрационный сценарий, не данные с площадки.

## Запуск

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000. Нужен интернет: three.js, Leaflet, шрифты и спутниковые снимки загружаются из сети.

## Файлы

- `index.html` — сцена и интерфейс
- `site-data.js` — модель площадки, снятая с чертежа
- `pv.js` — расчёт мощности панелей по цепочке PVsyst: однодиодная модель модуля, IAM, тепловая модель, двусторонность, потери в кабелях, инверторах и трансформаторах; параметры взяты из отчёта PVsyst по проекту
- `epc.js` — смета, экономика, график строительства
- `dev.js` — девелопмент: привязка к местности, расстановка столов по границе участка, сценарии, источники ресурса, площадки
- `oms.js` — эксплуатация: прогноз отказов, датчики, накопитель (демо-данные)
- `ui.js` — интерфейс новых экранов и карта

Что в новых экранах настоящее, а что демо, написано в сноске под каждым экраном.
